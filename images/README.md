## Sezione "Spazi" — completa

3 pannelli (toggle a 3 pulsanti come il menù), ognuno con una griglia di 4 foto. Tutte in uso in `index.html` (sezione `#terrazza`):

- **Terrazza** — `spazi-terrazza-1.jpg`, `spazi-terrazza-2.jpg`, `spazi-terrazza-3.jpg` (3 foto; la `-4` è stata rimossa su richiesta, il file resta nella cartella ma non è più referenziato in `index.html`)
- **Sale** (sala grande per feste + sala elegante) — `spazi-sale-1.jpg` … `spazi-sale-4.jpg`
- **Sala del Forno a Legna** (Pizzeria) — `spazi-pizzeria-1.jpg`, `spazi-pizzeria-2.jpg`, `spazi-pizzeria-4.jpg` (3 foto; la `-3` è stata rimossa su richiesta, il file resta nella cartella ma non è più referenziato in `index.html`)

Foto scelte dall'utente e ottimizzate per il web (ridimensionate, orientamento EXIF corretto). Schema nomi: `spazi-<sezione>-<numero>.jpg`.
